          ℹ️ How to use
          
Contact Mode:

          
    
            
  1. Insert your Estonian ID card into the reader
    2. 
            
  2. Click "Read ID Card" button
    3. 
            
  3. Personal data will be displayed
    4. 
            
  4. Data is cached for 5 minutes
    5. 
          

          
NFC Mode:

          
    
            
  1. Place your ID card on an NFC reader
    2. 
            
  2. Enter the 6-digit CAN from your card
    3. 
            
  3. Click "Read ID Card" button
    4. 
            
  4. Data is read using PACE protocol
    5. 
          

          
All Readers Mode:

          
    
            
  1. Insert cards into all available readers
    2. 
            
  2. Select "All Readers" mode
    3. 
            
  3. Each reader is queried with per-reader timing
    4. 
          

          
Troubleshooting:

          
    
            
  • Make sure the card is properly inserted/placed
    • 
            
  • Check that PC/SC service is running
    • 
            
  • For NFC: verify CAN is correct
    • 
            
  • Try removing and reinserting the card
